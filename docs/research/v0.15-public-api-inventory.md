packaging contract). `types` resolves dist/index.d.ts and `import` resolves
dist/index.js. No default export, CommonJS condition, public subpath, public
constant or importable symbol exists. Relative internal imports appearing in
.declarations are compiler plumbing, not supported package subpaths.

are shipped for internal module/declaration resolution only, not additional
public exports. TypeScript-private implementation fields are not public API even

is used only for operation/task UUIDs, not a crypto workload feature.

NaN, Infinity, negative/out-of-range and fractional integer options reject.
Zero is useful for maxQueue, maxRestarts, byte capacity/declarations and empty
ranges; it is invalid for worker counts, deadlines, grain, batch and count capacity.
Explicit undefined acts like omission for ordinary optional controls. Byte mode
uses property presence: omit unused byte keys entirely; `undefined` is invalid.
Constructor defaults use nullish coalescing, but null is not supported typed input.
Extra JS properties are not an option-discovery mechanism. Getters/proxies and
incorrect signal objects may throw synchronously; no blanket promise that hostile
or malformed JS option objects always reject asynchronously is made.

Factories must return `{ input, transferList? }` synchronously; throwing factories
fail the parent with contextual PjsError. Declaration callbacks are synchronous,
validated once for the next partition and cached while capacity is unavailable;
throws/invalid returns become PjsBinaryResultContractError. A declaration larger
than capacity fails with PjsResultCapacityError, rather than waiting forever.
