# Getting help with PJS

Start with the [README](README.md) and [core API guide](docs/guide/core-api.md).
For build, test, and contribution workflows, see [CONTRIBUTING.md](CONTRIBUTING.md).

Choose the appropriate form from
[New issue](https://github.com/Miskovy/parallel-javascript/issues/new/choose):

| Request                                             | Route                                                                                                                                                               |
| --------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Runtime bug, package/install problem, or type error | [Bug Report](https://github.com/Miskovy/parallel-javascript/issues/new?template=bug_report.yml)                                                                     |
| Feature or significant API/architecture proposal    | [Feature Request](https://github.com/Miskovy/parallel-javascript/issues/new?template=feature_request.yml) before substantial implementation                         |
| Performance regression                              | [Performance Regression](https://github.com/Miskovy/parallel-javascript/issues/new?template=performance_regression.yml) with repeated measurements and reproduction |
| Incorrect or unclear documentation                  | [Documentation](https://github.com/Miskovy/parallel-javascript/issues/new?template=documentation.yml)                                                               |
| General usage question                              | [Question / Support](https://github.com/Miskovy/parallel-javascript/issues/new?template=question.yml)                                                               |
| Security vulnerability                              | [SECURITY.md](SECURITY.md), through a private report                                                                                                                |
| Sensitive conduct report                            | Private maintainer contact described in [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md)                                                                                    |

The question form is available for usage questions; [GitHub Discussions](https://github.com/Miskovy/parallel-javascript/discussions)
are also enabled (verified 23 October 2026). Search existing issues and discussions
before posting, describe what you are trying to achieve, and include a small
reproduction when possible. Remove
credentials and personal information from public code and logs.

Functional bug reports do not need benchmark evidence. For performance claims,
include the environment, configuration, comparison, and repeated results requested
by the performance form. Maintainer time is limited; there is no guaranteed
response deadline or feature acceptance.
